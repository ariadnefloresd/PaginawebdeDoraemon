# Marca personal — Ariadne Flores

Landing page editorial para posicionar a Ariadne Flores como referente en transformación de negocios, productos digitales, excelencia de procesos, LXD e inteligencia artificial aplicada.

## Ejecutar localmente

```bash
python3 -m http.server 4173
```

Abre `http://localhost:4173`.

## Estructura

- `index.html`: contenido y estructura semántica.
- `styles.css`: sistema visual responsive.
- `script.js`: menú móvil, animaciones de entrada y contadores.
- `research/top-20-benchmark.md`: benchmark editorial y estrategia de posicionamiento.
